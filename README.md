# Controls

| Control | Action |
| --- | --- |
| A / D | Move left / right |
| Mouse | Aim |
| Space | Jump |
| S | Drop through a platform |
| Left Shift | Dodge |
| Left mouse | Fire |
| Right mouse | Rapidly fire |
| R | Reload |
| Esc | Menu |

Every control except aiming with the mouse and S can be changed in Key Bindings.

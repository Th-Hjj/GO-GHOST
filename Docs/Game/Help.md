# Configuration Help

Confirmed by Thomas, 2026-10-29. Body Configuration's Help opens two read-only pages named exactly **What're the controls?** and **What is configuration?**. Back or Escape returns to the same configuration and unfinished draft. Tabs have independent scroll positions and use the existing fonts, palette and controls.

The first page contains only A/D movement, mouse aim, Space jump, Left Shift Dodge, left mouse Fire, right mouse Rapidly fire and Escape pause/resume. Thomas's screenshot corrections remove the S entry, extra aim/fire/reload explanations, Training/Configuration navigation and the Pause and practice heading.

The second contains only Condition (when) and Action (what). Thomas's follow-up removes the Add and edit and Conditions and priority sections, including their headings and explanations. The help does not install a loadout or alter gameplay.

In a normal New Game on `main`, Happy supplies one editable Incoming Attack (Any) → Jump rule after character creation. Opening Help preserves that rule and any player edits. F8 contains Tuning, Waves and Analytics.

The **GO GHOST > Playtest > Help and Named Metrics** fixture includes historical assertions about Aim Assist. See the [implementation log](ImplementationLog.md) for the scope of past runs.

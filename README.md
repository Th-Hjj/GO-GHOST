# GO GHOST

GO GHOST is a single-player 2D action game where you control a fighter and set rules for when they act on their own.

## Play Beta 33%

- [Download for Windows (x64)](https://github.com/Th-Hjj/GO-GHOST/releases/download/beta-33/GO-GHOST-Beta-33-Windows.zip) — extract the ZIP and run `GO GHOST.exe`.
- [Download for macOS (Apple Silicon or Intel)](https://github.com/Th-Hjj/GO-GHOST/releases/download/beta-33/GO-GHOST-Beta-33-macOS.zip) — unzip the download and open `GO GHOST.app`.

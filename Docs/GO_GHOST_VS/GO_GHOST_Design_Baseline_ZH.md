## 1. 核心定位

GO GHOST 是一款单人、2D 横版射击游戏。整个游戏围绕同一个竞技场、同一个 cyberpsycho Boss 展开。玩家扮演前仆后继执行同一任务的警察，而不是扮演 Boss，也不是让同一位警察不断复活。

主题仍然是 **power 与 free will 的取舍**。空间与流程被压缩，但核心问题不变：

> 我愿意接受多少身体改造、交出多少自主控制，来完成这个任务？

第一层选择是愿意改造到什么程度；在这个程度内，第二层选择才是怎样安排火力、机动或防御，形成适合自己的打法。

## 2. 游戏流程

**新游戏 → 首位 0% 人类警察出击 → Boss 战。**

胜利分支：**战胜 Boss → 读取获胜者本次身体改造率 → 对应结尾。**

失败分支：**警察战败 → 下一位警察接替 → 自由配装 → 重新部署 → 再战同一个 Boss。**

每次部署后，玩家与 Boss 都恢复完整战斗状态。前辈造成的 Boss 伤害不保留；死亡不产生货币，也不继续解锁升级。

这是一段可以反复尝试的挑战，不是多关卡战役。升级界面不是新的可探索关卡。表中的阶段名称描述玩家流程，不要求一一对应独立 Unity Scene。

## 3. 首次出击与基本操作

每次真正开始一轮新游戏，首位警察固定为 **0% 身体改造**，携带基础武器。开局具备左右移动、鼠标自由瞄准、射击、跳跃和闪避；其他能力需要通过升级获得。

第一次战斗必须真实可胜，不安排强制死亡。玩家技术足够好，可以首次出击直接获胜并进入 0% 对应的结尾。剧情不能依赖玩家一定失败若干次才能成立，也不需要长篇前置叙事。

键位、闪避具体规则、空中闪避以及镜头行为尚未确定；不能把旧俯视角操作直接当作横版定稿。

## 4. 升级开放与自由配装

首次失败后，完整升级目录开放。之后安装、卸下与替换均免费，不使用货币、死亡奖励或逐次解锁制度。玩家可以始终拒绝身体改造，也可以直接选择高度改造。

配装在尝试之间编辑，进入战斗后锁定。战斗中不能换装，也不能在胜利后先卸下改造再改变结局。

“首次失败后全部开放”是获取规则，不表示 vertical slice 必须完成最终全部升级。Slice 中已经实现的选项应一次开放，不再额外安排解锁条件。

保留上次配装作为编辑起点可以作为界面建议，但不能自动替下一位警察增加改造。

## 5. 七个配装槽与身体改造率

| 配装槽 | 计入身体改造率 |
| --- | --- |
| 左手 | 是，独立计算 |
| 右手 | 是，独立计算 |
| 左腿／脚 | 是，独立计算 |
| 右腿／脚 | 是，独立计算 |
| 脊椎 | 是，独立计算 |
| 大脑 | 是，独立计算 |
| 武器 | 否，只改变攻击方式 |

英文表使用 Left Leg / Right Leg 表示左右下肢槽，与讨论中的左右脚对应。

**身体改造率 = 左手贡献 + 右手贡献 + 左下肢贡献 + 右下肢贡献 + 脊椎贡献 + 大脑贡献。**

各项贡献取决于当前装备的改造，而不是装过多少次或累计装过多少件。不同改造可以有不同权重；高影响的大脑改造有更大的百分比影响。六个身体部位的最高贡献合计定义为 100%，完全不改造为 0%。

具体权重、每个部位的升级选项与数值尚未确定，本版没有编造一套最终百分比。

**武器始终贡献 0%。** 它是攻击方式的选择，不是身体改造，也不直接参与结局判定。基础人类警察拿枪仍然是 0%。

## 6. 改造收益与控制权转移

改造总体上应让任务更容易完成。完整版的平衡目标是：0% 获胜困难但可行，100% 能让操作较弱的玩家明显更容易获胜。这不等于必须设计成自动通关或完全无敌。

代价同时通过外观、对白、结尾，以及真实的局内自动操作表达。不是每项四肢或脊椎改造都必须附带额外操作惩罚；某些改造的主要代价可以是提高改造率，而高影响脑部改造承担更明显的控制接管。

已确认的 slice 示例是 **AI 自动瞄准脑部模块**：

安装后，AI 可靠地追踪 Boss，接管枪口瞄准。玩家不能用鼠标覆盖它，也不能在战斗中关闭这个接管。移动、跳跃、闪避与开火时机仍由玩家控制。下一次出击前卸下模块，才恢复手动瞄准。

接管应当有用、稳定、可理解，不以随机拒绝指令、乱移动或故意失灵代替“失去自由意志”。界面与战斗反馈需要让玩家理解现在由谁掌控瞄准。

## 7. Boss 与结局

Boss 始终是同一个角色，但可以具备不同招式与行为状态。完整版允许多阶段；vertical slice 只要求一场成立的单阶段战斗。确切招式、节奏与数值还需设计，状态机还是行为树留待实际工程审查后决定。没有批准自动按玩家改造率缩放 Boss 的规则。

结局只取决于 **战胜 Boss 时，获胜警察当次配装的身体改造率**。不累计前辈的改造，不看死亡次数，不看曾经装过什么，不看武器，也不让最后的对白选择覆盖这个结果。

改造类型可以影响战斗和外观，但最终结局分支只通过它对总百分比的影响参与判定。同一最终改造率应遵守相同的结局映射规则。

结局数量、分界线、具体剧情与道德评价尚未确定。不能擅自将“高改造”写成坏结局、“低改造”写成好结局。

## 8. Vertical slice 范围

需要证明的闭环：

**一场成立的 Boss 战 → 一次真实失败与下一位警察接替 → 有意义的配装选择 → 下一场战斗中感到差异 → 与选择对应的后果反馈。**

具体包括可玩的横版基础操作、单阶段 Boss、完整失败重试、少量真实有效的改造选项、可见的改造率、AI 瞄准接管，以及基于获胜配装的简版结尾。不同测试配装需要能够产生可分辨的体验与后果。

优先验证：0% 首次获胜不会卡住流程；失败后能保持 0% 再战；更换武器不改变改造率；AI 接管在战斗中不能被关闭；胜利结局只读取本次身体配装。

完整升级目录、多阶段 Boss、独立教程、完整武器库、片头动画和精细结尾演出不是这次 slice 的前置要求。粗糙外观、提示文字和占位音频可以使用，但不能省略让玩家感知代价的反馈。

若测试需要临时权重或临时结局映射，必须标记为测试值，不得当作最终设计；也不能把未实现的完整改造目录宣称为已经完成。

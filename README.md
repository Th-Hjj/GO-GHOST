# GO GHOST

Single-player, fixed-camera 2D combat: Refraction (gunner), Severance (swordsman), then both together. Condition–Action V2 offers 26 conditions and 20 actions across five independent operations, sharing a total budget of five rules. Each rule is Primary Condition [AND Optional State Condition] → One Action. USC CTIN 489 — Thomas Hong and Walker Grupp.

## Open and play

Use **Unity 6000.6.0f1**, the existing packages and URP 2D renderer. Thomas uses Rider. The formal scene is `Assets/_Game/Levels/L01_Mission/Scenes/GO GHOST Duel.unity`; **GO GHOST > Combat > Open Arena** opens it. The Editor Play entry and Windows build use this scene, including when a different historical scene was last open.

Choose **New Game**, then **Add Rule → Select Condition → Select Action**. The body preview, Category / Options selector and complete right-hand Rule List stay visible together. A compact **+ AND** control optionally adds one state condition in the same editing flow; ordinary rules need no extra step. Conditions use **Body State, Weapon & Input, Position & Range, Threats, Actions & Results**; actions use **Aim / Fire / Dodge / Move / Jump**. Choose Grounded/Airborne, Close/Mid/Far, Any/Bullet/Melee/Low and Left/Right locally when required. Fire One Shot, Short Burst and Keep Firing show **Ammo Use: Allow Empty / Keep Two Rounds**, with Allow Empty as the visible default. Legal completed actions commit; Fire parameters can be inspected before its local confirmation. Cancel/Escape discards the complete draft. Edit IF/AND/THEN or action parameters from an existing rule. **Rules X/5** is one shared budget; at five, editing/removal/reordering remain available. Same-operation order sets first matching executable priority; temporary cooldown, collision, missing targets or resources permit lower-row/manual fallback. Other operations run independently. No Always, default rules, enable switch or hidden automatic mode. Finish or cancel editing before **Start Fight**.

The first configuration is empty/manual. The fight deep-copies rules and priorities; retry/next wave preserve them, New Game/Restart clears them. Each fight has a three-second stationary preparation and fresh actors/resources/observation. Victory advances; defeat opens reconfiguration; both Bosses defeated in wave three opens Complete.

The formal scene includes IBM Plex Sans for UI and IBM Plex Mono for compact counters. Rule activation changes color and a narrow glow while preserving glyph positions and wrapping. Add Rule and Start Fight share the right panel's bottom row. Layout targets are 1280x720, 1920x1080, 2560x1440 and 3840x2160; see the latest [validation log](Docs/GO_GHOST_VS/Implementation_Log.md) for actual checks.

Controls use closed inset frames, distinct hover/selection/keyboard-focus cues and dim disabled labels. Configuration retains five readable full rules, including AND and selected parameters, a separate body preview and fixed description area; combat action text wraps beside a fixed arrow column.

Wave 1/2 Bosses mirror the player's horizontal opening across the arena centre (currently player x=-9, Boss x=9). Wave 3 keeps the original x=9/x=3 Boss arrangement.

The fixed Rifle has 8 rounds, 12 damage, a .25 s interval and 1.2 s automatic reload. Aim rules select only eligible visible targets; Fire rules never change Aim. Arms use cyan, Legs mint and Dodge a narrow violet Spine. The right-side **Rules** list shows full conditions and parameters. It weakly emphasizes actual complete-rule matches; real accepted execution and ongoing ownership, including Hold, emphasize the action and arrow. Paid automatic Fire and accepted Jump/Dodge add local pulses, followed by brief fading edges without continued ownership. Manual actions stay neutral. The list is hidden for an empty loadout. The camera fits the entire arena beside it, and pause freezes feedback. Camo ends live target tracking. All player and enemy bullets pass through walls/platforms; bullets and the locked piercing beam still stop at allied Boss bodies. Each Boss has independent health. Both must die to clear wave three; simultaneous player death is defeat.

Movement rules stay horizontal. Keep Mid Range and Move Toward Center release ownership on arrival; Step Back is finite; Move Left / Right uses the chosen direction. **Hold Position** owns ordinary Move at zero without cancelling gravity, Dodge or knockback. **Hold Fire** blocks lower/manual Fire even during reload or at zero ammo; it does not cancel reload or existing bullets. Jump Once and Repeat Jumps use legal ground jumps. Fine-Tune Aim is legal with Enemy Near Aim Point alone; the raw aim-point test remains distinct from resolved weapon alignment. The first three Fire actions check their chosen ammo floor before each paid shot; Short Burst plans at most three available rounds from the current magazine. When automatic Fire cannot continue, manual fallback can spend reserved rounds. Dodge Along Movement uses resolved movement/facing; Dodge Toward Aim Point uses the original manual point. Cooldowns, cadence, reload and collisions remain unchanged. No hidden autonomous route or safety fallback. In Editor/development Wave 3, **P** requests alternating Cross Execution / Sweep & Drop attempts; legal rejections are logged without forcing placement, resources or hits.

Manual and automatic actions create real Jump Started, Jump Apex Reached, Landed, Dodge Finished, Shot Fired, Reload Finished and Hit Enemy events. Only successful formal Short Burst and Step Back responses emit Burst Finished and Step Back Finished. Events trigger from actual accepted/completed actions or positive damage, with bounded windows and independent row consumption. Optional states must match at the same time; two enemy-specific conditions must share the same enemy/source, subject to each condition's visibility requirements. A manual jump can start a burst, whose real completion plus Airborne can trigger a Dodge. Real action loops remain constrained by physics, ammo and cadence. Enemy Recovering, Enemy Reloading, Enemy Reappeared, Q03 and the old independent reserve-fire action are not selectable. **F8 developer tuning** is available in the Windows player and Editor. F8 opens/closes the panel; Escape also closes it. Opening pauses combat, and closing restores the previous pause state. Player, Weapon and Health tabs expose movement/jump speed, Dodge distance/movement time/cooldown/immunity, Rifle damage/bullet speed/shot interval/magazine/reload, and player/gunner/swordsman max/current HP. Type a value and press Enter or use - / +; ranges are enforced. Current HP requires a living actor and cannot exceed max HP. Values survive retry, waves and New Game for this app session; restarting the app or **Restore defaults** restores normal tuning. Shared assets and saved data are untouched. Existing shots, Dodge commitments and cooldown/reload deadlines finish with their original timing; new actions use edited values. Magazine increases fill on the next normal reload. Max-HP edits clamp current HP without healing. Controlled tuned fights are not normal-balance evidence.

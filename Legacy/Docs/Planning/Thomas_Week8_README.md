GO GHOST Alpha 50% adds run-local conditional loadouts to the existing three-wave Boss arena. Five independent operations offer two ordered WHEN/THEN rules, selected through the restored body diagram. There are 40 conditions and 30 responses. Rules temporarily take control; unmatched operations stay manual. Actual takeover lights the corresponding stickman limbs or weapon. Existing combat, music, resources and teammate files are retained; old save/ability progression is not enabled.

Controls: A/D move; Space jump; mouse aim; hold LMB fire; Left Shift horizontal Dodge; Escape pause. Select New Game, click Legs/Arms/Spine, choose the operation and Manual/Rules, add/edit/reorder up to two rules, then Start Fight. Rifle reloads automatically. Retry/next wave preserve the configuration; Restart clears it. The build folder includes the whole Windows player and audio licenses.

Hardware input, long sessions and all catalog combinations are not exhaustively tested. Natural three-wave completion is not claimed.

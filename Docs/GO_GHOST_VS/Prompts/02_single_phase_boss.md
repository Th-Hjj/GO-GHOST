# Prompt 02 — 可用 0% 警察挑战的单阶段 Boss

**Astra 思考档位：极高。请在客户端选择；本文件不修改客户端配置。**

先读取并遵守：
- 当前适用的 AGENTS.md、工程协作规则；
- Docs/GO_GHOST_VS/Execution_Contract.md；
- Docs/GO_GHOST_VS/GO_GHOST_Design_Baseline_ZH.md；
- Docs/GO_GHOST_VS/Prototype_Test_Profile.md；
- Docs/GO_GHOST_VS/Implementation_Log.md（若存在）。
需要核对 Macro 时，读取同目录原表或 Macro_Readable_Extract.md；不要从旧 README 推断新玩法已实现。
只执行本阶段，按 Execution_Contract 的格式交付，完成后停止。

目标：在同一个竞技场加入真正可战斗的单阶段 cyberpsycho Boss，先证明基础战斗，而不是先做升级让玩家变强。

使用已确认的基础人类配装：0% 身体改造，基础枪，无任何隐藏强化。
按 TEST-v0 制作两类攻击：可读的定向射击，以及可读的突进/近身攻击。招式不是最终定稿，所有数值集中配置并记录。
使用审查后最简单合适的行为实现；不为两招引入完整行为树库。

任务：
1. 完整接上 Boss 和玩家生命、受伤、死亡、Boss 被击败以及简单战斗结束提示。
2. 每招都有可辨认的预警、执行和恢复；初始出场不能立即无提示伤害玩家。
3. 移动、跳跃或基础闪避能应对每一招，0% 不能被规则性不可躲伤害或改造专属门槛堵死。
4. 人类基础枪能可靠伤害 Boss；Boss 不读取改造率自动调难度。
5. 碰撞/弹体伤害不能同一命中每帧无意重复触发。处理贴身、墙边、跳跃中和突进路径上的命中。
6. 战斗结束后禁止继续攻击和重复结算。此时只需要临时胜败显示；正式接替流程留给 03。
7. 维持同一个 Boss 身份和单阶段，不生成杂兵、第二个 Boss 或新关卡。

验收与证据：
- 可用实际操作击伤并击败 Boss；Boss 也能通过真实攻击击败玩家。
- 所有攻击的预警和命中区域可理解，有可复现的应对方式。
- 分别验证玩家死、Boss 死、同时致死的入口不会重复弹出结果。
- 若没有能力真人操作，不要宣称“0% 平衡已经通过”。区分代码可胜路径、调试强制胜利和真实 0% 实战胜利。
- 给我一组人类配装测试步骤，并列出第一版 Boss 参数及其实际存放位置。

只做单阶段基础战斗，不提前增加配装系统。

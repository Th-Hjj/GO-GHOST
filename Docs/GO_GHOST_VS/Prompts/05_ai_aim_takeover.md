# Prompt 05 — AI 瞄准接管与手动操作对照

**Astra 思考档位：极高。请在客户端选择；本文件不修改客户端配置。**

先读取并遵守：
- 当前适用的 AGENTS.md、工程协作规则；
- Docs/GO_GHOST_VS/Execution_Contract.md；
- Docs/GO_GHOST_VS/GO_GHOST_Design_Baseline_ZH.md；
- Docs/GO_GHOST_VS/Prototype_Test_Profile.md；
- Docs/GO_GHOST_VS/Implementation_Log.md（若存在）。
需要核对 Macro 时，读取同目录原表或 Macro_Readable_Extract.md；不要从旧 README 推断新玩法已实现。
只执行本阶段，按 Execution_Contract 的格式交付，完成后停止。

目标：落实本项目最关键的控制权取舍。现在实现并开放大脑槽的 AI Aim 模块（TEST 权重 40%）。

安装后：
- AI 稳定追踪当前 Boss，独占枪口瞄准；鼠标移动不能覆盖或短暂抢回它。
- 玩家仍自行移动、跳跃、闪避以及决定何时开火；松开射击键绝不自动射击。
- 战斗期间任何键、UI、设置或脚本装备入口都不能关闭接管。
- 只有尝试之间卸下模块，下一位部署时才恢复鼠标自由瞄准。

实现要求：
1. 明确“瞄准由谁写入”的单一权限来源，不允许旧手动脚本与 AI 同时争抢枪口。
2. 复用同一武器/弹体/伤害路径，不通过增加武器伤害、穿墙命中或修改 Boss 补偿接管。
3. 处理 Boss 在玩家左右两侧、跨越玩家、跳跃时、近距离重合、Boss 无效/死亡等情形。
4. 目标暂失效时保持安全的非手动策略，不悄悄回退鼠标控制。战斗结束按流程停止战斗。
5. 玩家移动方向、闪避方向和射击时机不被 AI 顺带接管。
6. 清楚显示 MANUAL AIM / AI-OWNED AIM；安装界面明确告知鼠标瞄准将在整次战斗中失效、下次出击前可卸除。
7. 增加粗糙但明确的脑部外观/准星变化，使接管看起来是设计而非输入 bug。
8. 对所有已实现模块同时开放；全装目前是 60%，不是 100%。

验证：
- 同一把枪、同一 Boss，比较未安装与已安装的实际射击方向；把鼠标移到 Boss 反方向时尤其明显。
- AI 装上后，松开射击键不产生新子弹，A/D 移动、跳跃与闪避仍由玩家决定。
- 尝试局内卸除/切换不能生效；失败后卸除，再部署立即恢复手动瞄准，无上一次遗留锁定。
- 反复在人工与 AI 配装间切换，没有监听重复、伤害叠加或百分比残留。
- 不凭自动命中测试宣称玩家一定喜欢这个取舍；实际易用性和自主感交给 playtest。

只完成可靠的瞄准接管，不新增 AI 自动移动、自动闪避或自动射击。

## 你验收后再推进
鼠标不能抢回 AI 瞄准，但你仍必须自己开火、移动、跳跃、闪避。

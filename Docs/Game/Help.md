# Configuration Help

> **Historical.** The Help page was removed on 2026-11-15. The game menu (pause key, or **Menu** on preparation pages) offers Resume, Configuration (in a fight or the Test Room), Key Bindings, Settings and Main Menu; the controls are on Key Bindings. See [UI Design: Override](UIDesign.md#screens), Menu (D9) and Help (D15).

Confirmed by Thomas, 2026-10-29. Body Configuration's Help opened two read-only pages named exactly **What're the controls?** and **What is configuration?**. Back or Escape returned to the same configuration and unfinished draft. Tabs had independent scroll positions and used the fonts, palette and controls of the time.

The first page contained only A/D movement, mouse aim, Space jump, Left Shift Dodge, left mouse Fire, right mouse Rapidly fire, R Reload and Escape pause/resume. Thomas's screenshot corrections removed the S entry, extra aim/fire/reload explanations, Training/Configuration navigation and the Pause and practice heading.

The second contained only Condition (when) and Action (what). Thomas's follow-up removed the Add and edit and Conditions and priority sections, including their headings and explanations. The help did not install a loadout or alter gameplay, and opening it preserved Happy's starter rule and any player edits.

A **GO GHOST > Playtest > Help and Named Metrics** fixture once held assertions about Aim Assist; it no longer exists. See the [implementation log](ImplementationLog.md) for the scope of past runs.

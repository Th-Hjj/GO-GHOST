# GO GHOST 配音工作台

从 Unity 的 **Tools → GO GHOST → Voice Studio** 打开。左边按 Happy 和 Final Boss 列出台词。选择一句，点 **播放游戏版** 就能听到游戏当前用的录音。

## 录入新台词

**改已有台词**：在工作台选中原条目，展开「改台词、换录音或单独调音色」，选择「按文字重新念」或导入对应的新录音。试听后点「保存这句到游戏」。沿用原来的资源名和游戏触发点。带玩家昵称的问候使用「调角色和整体声音」里的昵称问候台词，保留一个 `{name}`；固定的「默认问候」可以作为单句编辑。

**新增固定台词**需要同时登记台词和放入第一版录音。工作台按目录表生成左侧列表，选中条目时从磁盘读取它的 WAV。

1. 在 [VoiceStudioCatalog.json](../../Assets/_Game/Levels/L01_Duel/Resources/VoiceStudioCatalog.json) 的 `lines` 数组中添加一个对象。`key` 是唯一、长期使用的资源名，Happy 用 `Handler/`，Final Boss 会面用 `FinalBossVoice/`；斜杠后只用英文字母和数字。改词时保留这个 key。`label` 填方便查找的触发场合，`text` 填实际念出的台词。普通新句用 `locked: false`，跟随角色设置；开场特例继续使用已有条目。
2. 在目录表所在的 `Resources` 目录下放入 **`<key>.wav`**，路径大小写与 key 一致。使用 24 kHz、16 位 PCM WAV，Happy 的成品保留双声道。可以先放入这句的占位录音，再进工作台用干声或文字制作新版本。新 WAV 随 Unity 生成的同名 `.meta` 一起提交；替换录音时保留原 GUID。
3. 接入游戏触发点。Happy 的固定对白由对应的流程回调用同一 key 调用 `HandlerVoice.PlayLine`；上传阶段按目录预载固定配音。配置教程按目录顺序读取 `Handler/TutorialIntro` 和 `Handler/TutorialGoodbye` 开头的条目，每句使用独立录音。Mission 3 第一阶段直接开始倒计时。入侵波碰到玩家后战斗停时。`Handler/InvasionWarning` 确认写入，随后 Happy 按实际抽到的规则播放 Condition 和 Action 的成句录音，参数也一起读出。标记 `bonusOffer: true` 的条目在战胜 Boss 后播放，最后一页开放 Bonus 选择。标记 `transition: true` 的条目（`FinalBossVoice/Turn1` 至 `Turn3`）由 Boss 在第一阶段末跪地时按目录顺序播放，每句独立点击；第三句后释放 EMP。新增转阶段或 Bonus 台词时，标记对应的触发地点，并按确认的剧情顺序插入。[Happy 播放入口](../../Assets/_Game/Levels/L01_Duel/Scripts/HandlerVoice.cs) · [会面翻页逻辑](../../Assets/_Game/Levels/L01_Duel/Scripts/DuelGame.Progression.cs)
4. 重新打开工作台，在对应角色下找到新条目。点「播放游戏版」核对首版，再微调一个参数、生成并播放草稿。要验证角色联动，可以先在角色页试调并点「列出本次改动」，确认清单包含这句，然后放弃试调。只把要交付的版本保存到游戏；重开工具后应能听到已保存的版本，并由预定游戏事件播放同一句。保存产生的 `VoiceAuthoring/` 配方和归档素材随目录表、WAV 一起提交，供下一次编辑。

可参照现有的「默认问候」条目。下面的 key 对应 `Resources/Handler/Greeting.wav`：

```json
{
  "key": "Handler/Greeting",
  "label": "Greeting fallback",
  "text": "Nice to meet you.",
  "locked": false
}
```

## 调一句，听满意再保存

- **调整句**　在「调这一句」里，语速越大，说得越快。点「快 10%」会比当前速度再快一成。音调往右声音变高，音量往右声音变响。这些调整都从原素材计算。
- **只动一个词**　展开「只调某个词或停顿」，点波形下方的词。以 *Who are you?* 为例，先点「单独微调这句开场」。想让 *are* 和 *you* 靠近一点，选 *are* 后点「缩短 10 毫秒」。想让 *you* 收得慢一点，选 *you* 后把「发音时长」稍微往右拉。
- **选半个音或几个词**　在波形上拖出一段，点「把选区加为片段」。自动分词只是估算，展开「修正片段的名称和起止位置」可以按秒校正。缩短停顿时，把片段结束点放在安静处，以免切到词尾。
- **听修改前后**　「改完自动试听」会在你停下调整后生成并播放草稿。关闭时可点「生成试听草稿」，再点「播放草稿」。打开「循环试听」可反复听选中的一段，关掉可听整句衔接。也可以按住 F2 听游戏版，松开听草稿。
- **写入游戏**　满意后点「保存这句到游戏」。只想重来，展开「放弃修改或撤回保存」。其中「撤回最近一次保存到游戏」会恢复上次保存前的状态，包括上次一起保存的整批台词。

## 什么时候用折叠选项

| 想做到的事 | 在哪里操作 |
| --- | --- |
| 模仿自己念的节奏或情绪起伏 | 展开「跟着我的示范录音说」，选择念同一句的 WAV 或 M4A。「跟随节奏」调快慢，「跟随语调」调高低，「跟随重音」调轻重。 |
| 换词并听到角色重新念 | 展开「改台词、换录音或单独调音色」，选择「按文字重新念」，修改台词后生成草稿。要用自己录的版本，请选择念新词的录音。用自动转写的占位台词合成前，请先核对文字。 |
| 用录好的人声，加上角色的声音效果 | 在同一区域选择「导入人声，再加角色音色」。已有完整效果的文件选择「现有成品录音」。勾「批量改配音时跳过这句」可保留这句的单独处理。 |
| 用相近的音量比较读法 | 在「更多试听选项」打开「比较时拉近音量」。想比较实际响度时关掉。 |
| 听游戏触发时的效果 | 运行游戏时，在「更多试听选项」开启「通过游戏场景试听」。打开「游戏触发时临时播草稿」，下次触发这句会临时播放草稿。修改草稿、切换台词、结束运行或关闭窗口会清除临时替换。 |

## 调角色和整体声音

切到「调角色和整体声音」，在左侧选 Happy 或 Final Boss，在「试听文本」输入自己想听的中文、英文或混合句。点「用已保存声线朗读」和「用当前调整朗读」比较同一句。开启「改完自动试听」后，停下输入或调整滑杆就会读这段文字。切换角色会保留输入和待保存的设置；试听文本只用于本地试听。

两位角色使用相同的音色控件：电子感、贴耳回声、空灵回声、低沉声叠加量和粗粝感。常规语速、角色音量和音色分别保存，总音量由两个角色共用。想只改一句，回到「调这一句」，选中台词并打开「这句单独设音色」。

Happy 的「开场与昵称问候」可另行试听开场等待和玩家昵称。昵称模板保留一个 `{name}`。要听本次角色调整对正式录音的影响，点「列出本次改动」，逐句比较。

「列出本次改动」打开独立清单，显示每项设置的保存值、新值和影响的台词。只改播放音量或开场等待也会列出，可逐条听游戏版和草稿。点「返回调整」可以继续改，点「保存本次改动到游戏」才会写入。受保护的开场问句可在「调这一句」单独微调。

## 首次安装

在另一台电脑首次使用时，点「安装配音工具…」，选择 64 位 Python 3.12。依赖安装到项目的 `Library/VoiceStudio/venv`，首次安装需要联网。也可以从项目根目录运行 `python Tools/VoiceStudio/setup.py`。之后合成、参照录音分析和试听都在本机完成。

## 文件与恢复

运行时目录 `Assets/_Game/Levels/L01_Duel/Resources/VoiceStudioCatalog.json` 保存稳定资源名、台词、角色默认值和触发延迟。Final Boss 的页面文字和音频来自同一条记录。固定配音仍写入原 WAV，保留 Unity GUID。游戏只加载正式资源；新生成的昵称使用当前设置。

首次采用后，项目根目录的 `VoiceAuthoring/` 保存配方、按内容哈希归档的源音频、使用过的示范和上一次采用的恢复记录。若要跨机器编辑，请一并版本控制该目录、目录表和受影响的正式 WAV。采用使用示范的草稿时，该示范也会归档到制作素材中。单独试听的内容保存在 `Library/VoiceStudio/`。工作台本身不会提交或推送你的编辑。

工作台先生成候选文件，采用时校验试听文件、旧成品和目录版本。遇到外部编辑冲突请重新载入并试听。中断的写入会在下次工作台操作时从事务记录恢复。作者工具使用项目已有 Kokoro 模型；`Tools/VoiceStudio/author-voices.bin` 是制作声库的 Heart 和 George 条目，压缩的英式词典用于 Final Boss，授权见 `Assets/StreamingAssets/HandlerVoice/LICENSE`。两者位于玩家构建之外。

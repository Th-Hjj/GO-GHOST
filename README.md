# GO GHOST

Single-player, fixed-camera 2D combat: Refraction (gunner), Severance (swordsman), then both together. Alpha 50% offers 21 formal conditions and 19 responses across five independent operations, sharing a total budget of five rules. USC CTIN 489 — Thomas Hong and Walker Grupp.

## Open and play

Use **Unity 6000.6.0f1**, the existing packages and URP 2D renderer. Thomas uses Rider. The formal scene is `Assets/_Game/Levels/L01_Mission/Scenes/GO GHOST Duel.unity`; **GO GHOST > Combat > Open Arena** opens it. The Editor Play entry and Windows build use this scene, including when a different historical scene was last open.

Choose **New Game**, then **Add Rule → Select Condition → Select Action**. The independent body preview, middle selector and complete right-hand Rule List stay visible together (about 22/41/37). Both steps have Category / Options columns and a fixed description area. Committed body circuits stay dim; legal action/rule hover or focus previews the associated body system, and a completed commit plays one short connection flow. Condition categories are **Body State, Ammo & Reload, Weapon Control, Enemy State, Position & Range, Threats**; only Action uses **Aim / Fire / Dodge / Move / Jump**. Incompatible actions stay grey with inspectable reasons. A legal action immediately commits the pair; Cancel/Escape discards pending changes. Click either IF/THEN field to edit. **Rules X/5** is one shared budget; Add is disabled at five while editing, removal and **▲ / ▼** remain available. Reordering controls priority only among rules for the same operation; cross-operation edits keep the row's position. There are no persistent operation selectors, modes, enable switches or default rules. Finish or cancel editing before **Start Fight**. Each operation uses the first matching **executable** rule; temporary cooldown, collision, missing visible targets or resources allow lower-row/manual fallback. Different operations remain independent.

The first configuration is empty/manual. The fight deep-copies rules and priorities; retry/next wave preserve them, New Game/Restart clears them. Each fight has a three-second stationary preparation and fresh actors/resources/observation. Victory advances; defeat opens reconfiguration; both Bosses defeated in wave three opens Complete.

The formal scene includes IBM Plex Sans for UI and IBM Plex Mono for compact counters. Rule activation changes color and a narrow glow while preserving glyph positions and wrapping. Add Rule and Start Fight share the right panel's bottom row. Layout targets are 1280x720, 1920x1080, 2560x1440 and 3840x2160; see the latest [validation log](Docs/GO_GHOST_VS/Implementation_Log.md) for actual checks.

Controls use closed inset frames, distinct hover/selection/keyboard-focus cues and dim disabled labels. Configuration retains five readable rule pairs, a separate body preview and fixed description area; combat action text wraps beside a fixed arrow column.

# Retired presets

Thomas removed the preset system and death-based unlocking on 2026-10-29. Nothing replaces them: no page or F8 section offers preset preview or application. Runtime preset definitions and unlock subscriptions have been removed; old PlayerPrefs are unused.

Help, which held the controls and configuration pages after the presets, was itself removed on 2026-11-15; the controls are now on Key Bindings in the game menu ([UI Design: Override](UIDesign.md#screens)). Historical definitions and delivery evidence remain in Git history and the dated [Implementation Log](ImplementationLog.md).

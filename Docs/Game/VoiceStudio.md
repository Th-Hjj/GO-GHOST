# GO GHOST 配音工作台

从 Unity 的 **Tools → GO GHOST → Voice Studio** 打开。左边按 Happy 和 Final Boss 列出台词。选择一句，点 **播放游戏版** 就能听到游戏当前用的录音。

## 调一句，听满意再保存

- **调整句**　在「调这一句」里，语速越大，说得越快。点「快 10%」会比当前速度再快一成。音调往右声音变高，音量往右声音变响。这些调整都从原素材计算。
- **只动一个词**　展开「只调某个词或停顿」，点波形下方的词。以 *Who are you?* 为例，先点「单独微调这句开场」。想让 *are* 和 *you* 靠近一点，选 *are* 后点「缩短 10 毫秒」。想让 *you* 收得慢一点，选 *you* 后把「发音时长」稍微往右拉。
- **选半个音或几个词**　在波形上拖出一段，点「把选区加为片段」。自动分词只是估算，展开「修正片段的名称和起止位置」可以按秒校正。缩短停顿时，把片段结束点放在安静处，以免切到词尾。
- **听修改前后**　「改完自动试听」会在你停下调整后生成并播放草稿。关闭时可点「生成试听草稿」，再点「播放草稿」。打开「循环试听」可反复听选中的一段，关掉可听整句衔接。也可以按住 F2 听游戏版，松开听草稿。
- **写入游戏**　满意后点「保存这句到游戏」。只想重来，展开「放弃修改或撤回保存」。其中「撤回最近一次保存到游戏」会恢复上次保存前的状态，包括上次一起保存的整批台词。

## 什么时候用折叠选项

| 想做到的事 | 在哪里操作 |
| --- | --- |
| 模仿自己念的节奏或情绪起伏 | 展开「跟着我的示范录音说」，选择念同一句的 WAV 或 M4A。「跟随节奏」调快慢，「跟随语调」调高低，「跟随重音」调轻重。 |
| 换词并听到角色重新念 | 展开「改台词、换录音或单独调音色」，选择「按文字重新念」，修改台词后生成草稿。要用自己录的版本，请选择念新词的录音。用自动转写的占位台词合成前，请先核对文字。 |
| 用录好的人声，加上角色的声音效果 | 在同一区域选择「导入人声，再加角色音色」。已有完整效果的文件选择「现有成品录音」。勾「批量改配音时跳过这句」可保留这句的单独处理。 |
| 用相近的音量比较读法 | 在「更多试听选项」打开「比较时拉近音量」。想比较实际响度时关掉。 |
| 听游戏触发时的效果 | 运行游戏时，在「更多试听选项」开启「通过游戏场景试听」。打开「游戏触发时临时播草稿」，下次触发这句会临时播放草稿。修改草稿、切换台词、结束运行或关闭窗口会清除临时替换。 |

## 调角色和整体声音

切到「调角色和整体声音」可调两个角色共用的总音量，或分别调常规语速和音色。Happy 的电子感按百分比显示，贴耳回声和空灵回声可以分别调。开场等待秒数独立设置。昵称问候中的 `{name}` 会换成玩家的名字；点「听这句问候」可用测试昵称试听。如果昵称无法合成，会播放默认问候。

选 Happy 的「进入配置页」，再切到「调角色和整体声音」。把电子感从 **15%** 调到 **80%**，点「播放草稿」和「播放游戏版」作对照。15% 是现有成品原来的音色，向右增强电子层，向左减弱录音里的电子声。已有成品在 0% 时仍可能听到少量已经混进去的效果。节奏、停顿、词尾都沿用这次演绎。满意后点「列出本次改动」，逐句试听，再点「保存本次改动到游戏」。

贴耳回声和空灵回声用于未加效果的人声或重新合成的声音。想让角色重新演绎，展开「让角色按文字重新念现有成品」并选择角色。受保护的开场问句只在单句页面微调。总音量、昵称模板或开场等待可以单独保存。

## 首次安装

在另一台电脑首次使用时，点「安装配音工具…」，选择 64 位 Python 3.12。依赖安装到项目的 `Library/VoiceStudio/venv`，首次安装需要联网。也可以从项目根目录运行 `python Tools/VoiceStudio/setup.py`。之后合成、参照录音分析和试听都在本机完成。

## 文件与恢复

运行时目录 `Assets/_Game/Levels/L01_Duel/Resources/VoiceStudioCatalog.json` 保存稳定资源名、台词、角色默认值和触发延迟。Final Boss 的页面文字和音频来自同一条记录。固定配音仍写入原 WAV，保留 Unity GUID。游戏只加载正式资源；新生成的昵称使用当前设置。

首次采用后，项目根目录的 `VoiceAuthoring/` 保存配方、按内容哈希归档的源音频、使用过的示范和上一次采用的恢复记录。若要跨机器编辑，请一并版本控制该目录、目录表和受影响的正式 WAV。采用使用示范的草稿时，该示范也会归档到制作素材中。单独试听的内容保存在 `Library/VoiceStudio/`。工作台本身不会提交或推送你的编辑。

工作台先生成候选文件，采用时校验试听文件、旧成品和目录版本。遇到外部编辑冲突请重新载入并试听。中断的写入会在下次工作台操作时从事务记录恢复。作者工具使用项目已有 Kokoro 模型；`Tools/VoiceStudio/author-voices.bin` 是制作声库的 Heart 和 George 条目，压缩的英式词典用于 Final Boss，授权见 `Assets/StreamingAssets/HandlerVoice/LICENSE`。两者位于玩家构建之外。
